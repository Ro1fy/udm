# Ӟеча бура удмурт кыл

Офлайн-приложение для знакомства с удмуртским языком через короткие уроки и игры. Подходит для начинающих и младших школьников.

## Возможности

- Тематический словарь с переводом, транскрипцией и иллюстрациями.
- Шесть игровых режимов: выбор перевода, поиск лишнего слова, сортировка по темам, пары, сбор слова и «Правда или ложь».
- Локальная регистрация и вход; опыт, изученные слова и результаты игр сохраняются на устройстве.
- Слово дня и краткая справка об удмуртском языке в профиле.
- Настройки звука, уведомлений, геолокации и оформления.
- Светлое и тёмное оформление с природной палитрой: зелёный, тёплый белый и золотистый акцент.

## Запуск

```sh
flutter pub get
flutter run
```

Проверка статического анализа и тестов:

```sh
flutter analyze
flutter test
```
